Canteen Ordering and Billing System is a Python-based console application that simulates how a real canteen takes orders and generates bills. The project lets users browse a neatly organized menu, choose items from different categories, specify quantities, and manage their cart before confirming the order. It demonstrates a first-year student’s understanding of Python basics such as lists, dictionaries, loops, functions, and simple file handling. The goal of the project is to show how a simple automated system can reduce calculation errors and make the canteen service faster and more efficient.

The system includes several features such as categorized menus (Snacks, Beverages, Meals, Desserts), adding and removing items, updating quantities, calculating subtotals, and generating a final bill. The receipt is automatically saved as a text file so that it can be referred to later. The design focuses on clarity, simplicity, and a smooth user experience, making it both educational and practical.

The project is built entirely using Python without relying on external libraries. Dictionaries store the menu and item prices, lists are used for cart management, and functions help divide the program into logical sections. A text file is used to save the generated bill. The entire project is organized and maintained on GitHub, which helps keep the version history clean and the files easy to access.

To run the project, a user must have Python installed. After downloading or cloning the GitHub repository, they can open a terminal inside the project folder and run the file named “canteen.py” using the command python canteen.py. The program then guides the user through the ordering process automatically, so no extra setup is required.

Testing the program can be done by selecting various menu options, adding different quantities, removing items, and verifying whether the final bill shows the correct totals. Users can also check the generated text file to confirm that the receipt is saved properly. Error-handling can be tested by entering invalid inputs like non-numeric values or negative quantities to ensure that the system responds correctly. Screenshots can later be added to the project to visually show the menu display, cart updates, and the final bill.
